About Project

Digital Warranty Card is a web-based project that helps users store and manage product warranty information digitally.

Technologies Used

  • HTML - Website Structure
  • CSS - Website Design
  • JavaScript - Functionality
  • Local Storage - Saving Data in Browser

Features

  • Login screen
  • Add product warranty
  • View saved warranties
  • Search and filter warranties
  • Check active and expired warranties
